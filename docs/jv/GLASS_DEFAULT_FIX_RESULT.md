# Исправление комплектационного режима: стекло по умолчанию выключено

## Основание

Владелец подтвердил: в режиме комплектации стоимость стекла по умолчанию не включается. В исходной книге `Настройки!D32=false`. Диагностика и Excel-сравнение: `LINE_PRICE_INVESTIGATION.md`; компактный повторяемый снимок результатов: `fixtures/line-glass-default-parity.json`.

## Поведение

- Новый UI-контракт `JV-UI-INPUTS-3` использует D32=false для комплектации: Line и Zigzag, связанные с D32 работы Slider, и выключенное стекло Front. Розница не изменена. Контракты UI-1 и UI-2 сохраняют старую интерпретацию, чтобы исторические заказы не пересчитывались молча по новым настройкам.
- Для JV-Line контрольный случай 4000 × 2500 мм / 5 створок / паркуемая дверь: Excel и движок отображают **160 426,02 ₽** при D32=false; при D32=true отображали **240 211,40 ₽**. Это DISPLAY_MATCH, не точное равенство внутреннего представления. Иные размеры и варианты не исследовались в рамках этого исправления.
- Для остальных семейств и смешанных заказов при новом комплектационном режиме отдельная Excel parity стекла off ещё не проведена. Результат принудительно PARTIAL без подтверждённой цены и итога; его нельзя зафиксировать как коммерческий снимок. Это временное ограничение безопасности, а не доказательство отсутствия расчётной логики.
- Для нового КП нельзя использовать старый комплектационный снимок UI-1/UI-2 с прежними настройками, включая создание новой версии его условий. Старые документы и снимки остаются доступны для просмотра. Для фиксации текущего расчёта старый заказ нужно явно пересчитать и сохранить с UI-3.
- Финансовые данные, исторические документы и исходные книги не переписываются; migration БД не требуется. Демо Docker не обновлялся.

## Проверки

Оригинальная книга Excel 16 пересчитана на временных копиях при D32=false и true; формулы и значения Q52:Q58 проверены с тестовым JV-Line. Прошли backend API, 205 JV-тестов, 4 изолированных PostgreSQL-теста, браузерные тесты черновика КП и текущего результата, сборки и HTTP-интеграция. Для оставшихся семейств воспроизводимые числовые Excel parity остаются задачей до включения итоговых цен.
