# JV-Line Lab: отчёт функциональной проверки

## Проверки кода и сценариев

- JV unit/parity suite: см. итог PR_08; в него включено 20 разнообразных Excel `CalculateFullRebuild` сценариев (10 на книгу) по всем Q52:Q58 и 2 сценария коммерческого селектора F28=2.
- Контракт выходов Lab проверен через общий `calculateLineConstruction`: геометрия, базовая и дополнительная BOM, клей, стекло, покраска, Q55/Q57, Q56/Q58 и trace имеют результаты; при доступной полной поддержанной ветви адаптер выставляет `finalPriceAvailable=true`.
- Страница `apps/frontend/src/modules/jv-line/JVLineLabPage.tsx` читает локальный versioned JSON и вызывает общий расчётный модуль; расчёт не вызывает legacy `/calculate`, Prisma или производственные сделки/БД.

## Ограничение визуального smoke-test

`pnpm dev:frontend -- --host 127.0.0.1` поднял Vite на `http://localhost:5173/`, но встроенный браузерный surface Codex не смог подключиться к loopback: `ERR_CONNECTION_REFUSED` для `localhost:5173` и `127.0.0.1:5173`. Попытка выбора уже открытого Windows Edge остановлена runtime Computer Use из-за невозможности однозначно определить активный URL. Поэтому визуальное отображение после авторизации и интерактивный ввод в реальном окне **не подтверждены**. Проверены сборка и тесты компонента/общего движка; авторизация и изменение полей вручную не заявляются.

Не подключались к production backend/DB и не создавали тестовые сделки. Для полного UI smoke-test требуется доступный браузеру dev host и изолированная тестовая авторизационная среда.
