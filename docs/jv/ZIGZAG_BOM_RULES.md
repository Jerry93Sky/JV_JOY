# JV-Zigzag: подтверждённые количества BOM (Z1)

Источник: обе оригинальные XLSM, SHA-256 в `fixtures/zigzag-geometry-excel.json`; восемь свежих пересчётов Excel 16 `CalculateFullRebuild` на временных копиях.

| Количество | SKU | Материал | Ед. | Формула Excel | Условие |
|---|---|---|---|---|---|
| N9 | LN-070-A | Роликовая каретка высокая | шт. | `=(D5-1)*D6` | активная створка |
| N10 | LN-080 | Защёлка боковая | шт. | `=D5*D6` | все створки/открывания |
| N13 | LN-120 | Поворотный узел нижний, комплект | комплект | `=D6` | каждое открывание |
| N14 | LN-130 | Поворотный узел верхний, комплект | комплект | `=D6` | каждое открывание |
| N16 | LN-180 | Спейсер | шт. | `=N9` | наследует каретки |
| N17 | LN-TL | Заглушка верхняя рядовая левая | шт. | литерал `0` | подтверждённый ноль |
| N18 | LN-TR | Заглушка верхняя рядовая правая | шт. | `=IF(D6=2,2,0)` | два открывания |
| N19 | LN-TF | Заглушка верхняя боковая плоская | шт. | `=IF(D13="ДА",0,2)` | отсутствует опция D13 |
| N27 | LN-210 | Верхняя петля + башмаки + винты | комплект | `=D5*D6-D6` | количество створок за вычетом открываний |
| N28 | LN-220 | Нижняя петля + башмаки + винты | комплект | `=N27` | наследует N27 |
| N32 | AA-050 | Уплотнитель светопрозрачный h-типа, 3 м | шт. | `=D6*D5-1` | по числу створок/открываний |

Реализация: `packages/shared/src/jv/zigzag/material-quantities.ts`. Каждая позиция содержит source-cell trace и версию каталога. Список — подтверждённое подмножество, не полный BOM: Z1 содержит 31 строку количества N5:N35; оставшиеся строки с зависимостями от геометрии, настроек, условных аксессуаров, клея/активатора пока не объявлены поддержанными. Нулевые и условные количества не отождествляются с отсутствующими правилами.
