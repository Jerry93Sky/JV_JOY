# JV-Zigzag: подтверждённые количества BOM (Z1)

Источник: обе оригинальные XLSM, SHA-256 в `fixtures/zigzag-geometry-excel.json`; восемь свежих пересчётов Excel 16 `CalculateFullRebuild` на временных копиях.

Реализация: `packages/shared/src/jv/zigzag/material-quantities.ts`. Каждая позиция содержит source-cell trace и версию каталога. Список — подтверждённое подмножество, не полный BOM: Z1 содержит 31 строку количества N5:N35; реализовано 18, оставшиеся 13 требуют дополнительных геометрических/табличных зависимостей и заказа/расходных правил. D14/D15/D17 теперь выводятся из исходных индексов настроек и ячеек `#1`; готовые значения Excel не передаются в движок. N17=0 — формульный ноль; N8=0 при D13="НЕТ" — условная нулевая позиция. Нулевые и неизвестные количества не отождествляются.
