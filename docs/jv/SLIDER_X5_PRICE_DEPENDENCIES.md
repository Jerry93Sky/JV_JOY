# Slider-X5: путь стоимости для PR_11J

В пересчитанных Excel 16.0 копиях обеих книг `Главная!F11=6 → G11=3 → S1!A3=1`, поэтому активен лист `S1`. `S1!M53` имеет формулу `=IF($D$6<=2,SUM($M$51:$M$52),"ОШИБКА !")`; `Главная!T11='S1'!$M$53/Настройки!$D$13`; `Главная!Y11=INDEX(R11:X11,G11)*(100+Настройки!$D21)/100`. Заголовок столбца W содержит название Slider-X5, однако формульный `G11=3` направляет расчёт на T11. Это надо сохранить при переносе, не выбирать столбец по заголовку.

```text
F11=6, размеры/створки/открывание, Настройки и #1
  → S1 C8=20, C9=5, C10=25, D3:D6, D17:D28
  → геометрия D31:D45 → X5 K5:K46
  → цены L5:L42 из Прайс-Slider и настройки режима → M5:M42 → M47
  → стекло/обработка D47:D53 → M49; окраска R5:R27 → M48
  → дополнительная работа/ширина/фиксатор → M50
  → общие расходы ПРМ!AB25 → S1!T5; Клей+акт!O5/O18 → M40/M41
  → M51 (материалы, работы, надбавка F28), M52 (сборка/монтаж)
  → M53 → Главная!T11 → Главная!Y11
```

Отличия X5 от X3 в подтверждённой количественной части: K6/K10 вместо K5/K9, `D44` использует `Настройки!S24` вместо S23, `D36` использует S19 вместо S18, а K33 умножает ширину на C9=5 вместо 3. Поэтому даже при совпадении текста стоимостных формул суммы и возможные каталожные строки отличаются. Отличие от L5 — X-опора K10, X-створочный K13, X-заглушки K18:K21, X-каретка K24 и X-задвижки K31/K32 вместо L-ветвей.

Для переноса цен нужно отдельно подтвердить X5 `Прайс-Slider` и оба профиля `L5:L42/M5:M42`, стекло из `Прайс-Стекло`, окраску и `Прайс-сб+монт`, `M47:M53`, `T11/Y11` на самостоятельных X5 сценариях. Существующий коммерческий граф X3 — кандидат на безопасное переиспользование узлов с одинаковыми выражениями, но X5 нельзя объявить `COMPLETE` до собственной проверки этих адресов и отображаемой стоимости M53.

K40/K41 в реализованном BOM — расход одной конструкции. На уровне позиции заказа он умножается на число конструкций; `Клей+акт` суммирует расход всех позиций, округляет закупочные упаковки на весь заказ и распределяет стоимость через O5/O18. `ПРМ!AB25` зависит от площади и числа изделий всех строк заказа. Для X5 собственное распределение и цена пока не реализованы. Не допускается начислять минимальную упаковку на каждую конструкцию отдельно или принимать сохранённый Excel Value2 за готовую цену движка.
