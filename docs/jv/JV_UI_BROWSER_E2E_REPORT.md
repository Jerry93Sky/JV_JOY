# PR_15A: browser E2E

Команда: `pnpm --filter frontend test:jv-browser`. Тест `apps/frontend/scripts/test-jv-order-browser.mjs` запускает настоящие Vite и Fastify на изолированных локальных портах, открывает приложение в headless Google Chrome через Playwright и выполняет настоящий HTTP-запрос к JV Engine. Prisma production DB не используется. Секрет создаётся случайно в памяти на время процесса; JWT подписывается через обычный Fastify JWT-плагин и помещается в auth store только браузерного тестового контекста. Авторизация приложения не отключается.

Проверены: USER не имеет доступа; ADMIN открывает редактор; создание семи разных систем и лимит слотов; изменение ширины Line; ограничения дверных настроек Front; общая транспортная опция 2; получение COMPLETE через backend, отображение итога; сброс старой цены после изменения размера и перерасчёт; RETAIL и повторный расчёт; PARTIAL с отключёнными стеклом и отделкой Front без итоговой цены; отображение ошибки HTTP 500. Ошибка 500 намеренно моделируется сетевым перехватом Playwright; остальные расчётные ответы идут от настоящего backend. Проверяется отсутствие необработанных page errors.

Локальный Chrome E2E: PASS. Компонентный React Test Renderer + реальный HTTP-тест сохраняется отдельно и не называется браузерным тестом. Локальный тест не заменяет отдельное сравнение новых сочетаний с Excel и не доказывает parity всех селекторов. В CI используется системный Google Chrome (`channel: chrome`), версия Playwright закреплена в lockfile.
