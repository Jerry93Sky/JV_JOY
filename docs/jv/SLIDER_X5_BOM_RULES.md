# Slider-X5: материальная спецификация S1!K5:K46

`calculateSliderX5FullBom` в `packages/shared/src/jv/slider/x5-bom.ts` вычисляет 29 применимых позиций из исходных размеров, геометрии, настроек и справочников селекторов `#1!F24:F26/G24:G26/F29:F32/G29:G31`. `S1!D22` вычисляется отдельным DAG-узлом из `Настройки!I27` и `S1!C22`; готовое D22 из Excel не передаётся на вход. Количества K6 и K10 поступают из геометрического DAG. Все 42 адреса, артикулы, наименования, единицы, формулы, зависимости и 10 статусов применимости содержатся в `SLIDER_X5_BOM_COVERAGE.json`; значения Excel, рациональные результаты и trace — в `SLIDER_X5_EXCEL_PARITY.json`.

| Строки | Технологическая роль и ветви |
| --- | --- |
| K5:K13 | Для X5 активны пятидорожечный верхний профиль K6, X-опора K10, боковой K11, X-створочный K13. Трёхдорожечные K5/K9, L-опоры K7/K8 и L-створочный K12 неприменимы. D36 для K11 выбирает `Настройки!S19`, когда C10=25. |
| K14:K22 | L-заглушки K14:K17 неприменимы. X-заглушки K18:K21, включая выбор направления и `H21`, и демпфер K22 вычисляются по исходным формулам. |
| K23:K32 | X-каретки K24, ручки K25/K26, замки K27/K28 и X-задвижки K31/K32. L-каретка K23 и L-задвижки K29/K30 неприменимы. `INDEX` для D20/D24/D26 воспроизводит `#1`; применимая строка может законно дать ноль. |
| K33:K39 | Щёточный уплотнитель K33 содержит `0.001*D3*C9*2`: множитель пяти дорожек в X5 отличается от X3. Остальные уплотнители зависят от D17, H19, H25 и створок. |
| K40:K42 | Расход активатора, клея и саморезов на **одну конструкцию**. K40/K41 используют Excel `ROUNDUP` с точностью 0 либо 3 знака по `Настройки!L6`; K42 округляется вверх до целого. |
| K43:K46 | Крепёж заглушек, X-кареток и X-задвижек. K45 для L-задвижки неприменим. Для K43/K44/K46 артикул оставлен `null`, поскольку однозначный SKU не подтверждён; количество вычислено. |

По пяти сценариям каждой книги применимы **29 строк**: K6, K10, K11, K13, K18:K22, K24:K28, K31:K44 и K46. **13 неприменимых**: K5, K7:K9, K12, K14:K17, K23, K29:K30, K45. Для первых 12 неприменимых строк исходный J-селектор равен нулю во всех 10 пересчётах; K45 не имеет собственного J и равна `2*K29=0`. `SLIDER_X5_BOM_COVERAGE.json` сохраняет значения и формулы J для каждой строки/сценария. Неприменимость не смешивается с формульным нулём применимых строк. Вариант `H21=0` проверяет альтернативную ветвь X-заглушек.

Справочник цен `Прайс-Slider` указан в происхождении позиции, но стоимостные правила X5 пока не реализованы. `Настройки!D6/D8/S7/S19/L4/L5/L6/H19/H21/H23/H25/H27` участвуют в количествах. K40/K41 нельзя выставлять в коммерческую стоимость как отдельную полную закупочную упаковку каждой конструкции: order-формулы `Клей+акт` сначала суммируют расходы, округляют упаковки на весь заказ и распределяют стоимость. Для X5 подтверждён расход конструкции; распределённая стоимость относится к PR_11J.

Сценарии охватывают указанное подмножество условий. Другие комбинации селекторов и ограничения размеров требуют дополнительных пересчётов перед заявлением универсальной эквивалентности.
