# JV-Line: покрытие BOM после PR_05

Полная таблица источников и статусов находится в `LINE_MATERIAL_COVERAGE.json`. Обе книги используют одинаковые артикула, описания, единицы и формулы количества для L1 строк 5–44. Новые формулы реализованы поверх точной десятичной арифметики и существующего DAG; значения берутся из явно переданных ячеек/параметров, без молчаливых defaults.

## Новые подтверждённые формулы

| SKU | Excel quantity cell | Исходное выражение | Реализация / зависимости |
|---|---|---|---|
| LN-040 | `L1!O8` | `=IF($D$15="ДА", 2*$D$33/1000+Настройки!$D$8/1000, 0)` | `bom-line.ts`; D33 вычисляется отдельным trace шагом из D4, D15, `Настройки!P3` |
| LN-TL | `L1!O28` | `=IF($D$7="НАЛЕВО",2*$D$5-2,0)+IF(AND($D$7="ДВУХСТОР",$D$5<=3),2,0)+IF(AND($D$7="ДВУХСТОР",$D5>3),2*($D$5-2),0)` | D5/D7; верхние левые рядовые заглушки |
| LN-TR | `L1!O29` | `=IF($D$7="НАПРАВО",2*$D$5-2,0)+IF(AND($D$7="ДВУХСТОР",$D$5=2),2,0)+IF($D$7="ДВУХСТОР",2*$D5-2-$O$28)` | D5/D7/O28; верхние правые рядовые заглушки; пустая ветвь IF ведёт себя как 0 в арифметике Excel |
| LN-BL | `L1!O33` | `=$O$28` | Ссылается на LN-TL |
| LN-BR | `L1!O34` | `=$O$29` | Ссылается на LN-TR |
| LN-BF | `L1!O35` | `=$O$30` | Ссылается на LN-TF |
| LN-BSL | `L1!O36` | `=$O$31` | Ссылается на LN-TSL |
| LN-BSR | `L1!O37` | `=$O$32` | Ссылается на LN-TSR |
| LN-T90 | `L1!O38` | `=$D$8*IF($D$9=90,1,0)` | L1 D8 и фиксированный workbook literal D9=90 |
| LN-B90 | `L1!O39` | `=O38` | Ссылается на LN-T90 |
| LN-230 | `L1!O42` | `=IF($D$19="ДА",1,0)` | Требует фактического L1 D19 |
| LN-240 | `L1!O43` | `=IF($D$20="ДА",$D$6,0)` | Требует фактического L1 D20 и D6 |

LN-040 принимает разрешённые ячейки промежуточной геометрии и трассирует D33: `=IF($D$15="ДА",($D$4-Настройки!$P$3),0)`. D4 и Настройки P3/D8 — миллиметровые входы этой формульной ветки; параметр D9 не превращён в пользовательскую настройку и остаётся литералом 90 исходной книги.

## Полнота для конфигурации

При всех необходимых входах в 10 Excel-прогонах выдаются 26 подтверждённых строк и 14 неподдержанных. Если отсутствуют L1 D8, D19/D20 — соответствующие четыре условные строки остаются в `unsupported`. Если отсутствуют D4/Настройки P3/D8 для LN-040, эта строка тоже остаётся неподдержанной. BOM не считает неподдержанное значение нулём, а нулевые строки LN-210/LN-220 сохраняет как реальные нулевые строки из исходной книги.

## Остающиеся строки

| SKU | Excel cell | Причина |
|---|---|---|
| LN-020, LN-030 | `O6:O7` | Требуется сумма F39 створочных профилей и настройка D6; F39 зависит от раскроя F33:F38 и рядов створок 46–51 |
| LN-070-A/B/C | `O12:O14` | Зависит от парковочных состояний D23/D24, выбранной позиции C24 и валидатора геометрии |
| LN-080, LN-090 | `O15:O16` | Две таблицы ПД плюс ветка парковки/валидации; таблицы доступны, но полная зависимая цепь не перенесена |
| LN-100, LN-110 | `O17:O18` | Зависят от предыдущих защёлок/переключателя D16/D17 |
| LN-120, LN-130 | `O19:O20` | Зависит от D20 и D6; эта ветка не активирована без корректно разрешённой опции |
| LN-190, LN-200 | `O26:O27` | Зависит от LN-070-B/парковочного состояния |
| AA-010 | `O44` | Зависит от O7 и коэффициентов `Настройки!L7/P21`; формула ROUNDUP ещё не перенесена |

Excel parity на PR_05: 260 количества (240 EXACT, 20 совпадают по формату `0,000`; 0 mismatch) и 260 сумм стоимости (181 EXACT, 79 совпадают по денежному формату; 0 mismatch). Числовые основания сохранены по каждой строке в `LINE_MATERIAL_PARITY.json`.

Отдельно в Excel существуют шесть дополнительных material rows `L1!O45:O50` (AA-020, AA-050, AA-070, AA-090, AA-110, AA-120), не входящие в исходную 40-строчную карту L1!O5:O44. Они включены в Excel формулу `L1!Q52=SUM(Q5:Q50)`, но не добавлены в текущий каталог BOM. Точные формулы этих строк и зависимостей итоговой стоимости приведены в `LINE_PRICE_RULES.md`; Q52 поэтому не является эталоном текущего поддержанного subtotal.
