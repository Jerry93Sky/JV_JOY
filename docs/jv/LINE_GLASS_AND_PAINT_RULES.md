# JV-Line: стекло, заполнение и покраска

## Стекло/заполнение

Выбор `Главная!I11` передаётся в `L1!C11`, выбирая имя/толщину из `#1!D11:D22` и цену по индексу из `Прайс-Стекло!D5:D16`. Используется отдельный снимок цен для каждой исходной книги; отсутствие или несовпадение прайса приводит к ошибке, не к подстановке нуля.

Для строк `L1!43:48` движок использует количества полотен `C46:C51`, ширины заполнения `D46:D51` из геометрических промежуточных результатов створочного расчёта, высоту `D45 = D4 - Настройки!P19`, цену кв. метра, множители `Настройки!L17/L18`, переключатель `L21` и пересчёт площади из мм² в м² `/1000000`. Формулы отдельных строк `F43:F48` сохранены в trace; строковые суммы `G43:G48=C46:C51*F43:F48`, итого `G49=SUM(G43:G48)`. Толщина выбранного заполнения для `I55` берётся из `#1!D11:D22` и умножается на `Настройки!L22`.

`D54 = G49 + 'Прайс-сб+монт'!C23*X5`; `Q54 = IF(Настройки!D32,D54,0)`. В изолированном слоте JV-Line X5 равен `1/Главная!Z11`, что проверено по `ПРМ!AB25` при нулевых количествах других систем. Справочник снимков: `docs/jv/fixtures/line-glass-price-snapshots.json`. Реализация: `packages/shared/src/jv/glass-line.ts`.

**Сверка:** Excel 16 `CalculateFullRebuild` для обоих ценовых профилей, стекло index 9: площадь панели `D45=2352` мм; `G49`, `D54`, `Q54` соответствуют отображению Excel до 2 знаков. Для рациональных сумм, которые не равны Excel binary64 `Value2` десятичным числом, классификация остаётся `DISPLAY_MATCH`, а не числовым равенством.

## Покраска

Реализована ветвь JV-Line `V5:V12` на основе количества соответствующих строк BOM `O5:O12` и ставок `Прайс-Line!G5:G12`. `V13=SUM(V5:V12)*IF(C10=4,Настройки!L11,1)` учитывает множитель выбранного финиша «муар»; `V14=Настройки!L9*Настройки!L10*X5` — минимальную стоимость на распределённый системный слот; `V15=MAX(V10:V14)` выбирает максимум по исходному диапазону, `V17='Прайс-сб+монт'!C24*X5`, `V18=V15+V17`, `Q53=IF(C10<>1,V18,0)`.

Расчёт оставляет десятичные значения точными рациональными, не округляет деньги. Цены профиля и правила записаны в `docs/jv/fixtures/line-paint-price-snapshots.json`; реализация — `packages/shared/src/jv/paint-line.ts`.

## Проверенные ветви

В Excel временно изменялись только копии книг. Для каждого из двух профилей проверены финиши 1–4: Q53 равен нулю при финише 1, ненулевой минимальный/расчётный расход проходит для финишей 2–4; отдельно включён/выключен D32. Сквозные разнообразные сценарии также меняют индекс стекла и финиша. Конфигурация ограничена одним слотом JV-Line, Z11=1, Z12:Z17=0. Смешанный заказ нескольких систем требует отдельной сверки X5/AB25 и распределения общих минимумов.
