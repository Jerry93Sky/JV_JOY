# PR_12B2: стоимость стекла Front

Источник: оригинальные JV-комплектация и JV-розница от 08.10.2026, листы F1, Прайс-Стекло, Настройки, Прайс-сб+монт. Снимки исходных литералов и SHA-256: fixtures/front-commercial-component-snapshots.json. Контрольные результаты получены только из временных копий Excel 16 после CalculateFullRebuild: fixtures/front-commercial-components.xlsx.json.

| Выход F1 | Подтверждённое правило | Источник |
| --- | --- | --- |
| G28 | INDEX(Прайс-Стекло!D5:D16, C7) | C7 = Главная!I11 |
| G29, G30, G31 | G28 × Настройки!L18; G29; G28 × Настройки!L17 | L18=1.21, L17=1.05 в обеих книгах |
| H28:H31 | Cстрока × Dстрока × Eстрока × Gстрока / 1000000 | C/D/E даёт Front geometry |
| H32 | SUM(H28:H31) | сумма стеклянных позиций |
| D35 | H32 + Прайс-сб+монт!C23 × Y5 | C23: комплектация 5625, розница 4500 |
| S35 | IF(Настройки!D32, D35, 0) | переключатель D32 |

Тип стекла выбирается исходным селектором Главная!I11. Снимки цен разделены по книге и сверяются с SHA-256 геометрии. Например, Прайс-Стекло!D13 (селектор 9): комплектация 6869.090909090908, розница 3778; перенос одного прайса в другой профиль запрещён. Отдельно сохранены площадь каждой из четырёх деталей, ставка, сумма, адреса справочников и TraceStep. Нулевые количества остаются формульными нулями, а неизвестная активная ставка даёт PARTIAL с диагностикой.

Y5 не берётся из кэша: ПРМ!AB25 вычисляется по исходным размерам и количествам всех строк заказа Главная!11:17. Если не передан полный контекст, расчёт доли отклоняется; зависимые включённые компоненты дают PARTIAL. S35 может быть нулём при выключенной D32, хотя H32 и D35 вычисляются в Excel.

Отдельный флаг «совсем без стекла» не подтверждён формулами F1: даже при нулевых H28:H31 формула D35 содержит C23×Y5. Поэтому вход glassEnabled=false намеренно возвращает PARTIAL, пока не найден исходный селектор и его ветвь; он не превращает весь компонент в доказанный ноль. Проверенные выключенные случаи относятся к Настройки!D32, которая отключает S35.

Реализация: packages/shared/src/jv/front/glass-pricing.ts и commercial-context.ts. Сравнение: FRONT_COMMERCIAL_COMPONENTS_PARITY.json. Это компонент S35, не финальная цена S38.
