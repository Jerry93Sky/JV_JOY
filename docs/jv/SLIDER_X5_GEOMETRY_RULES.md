# Slider-X5: проверенная геометрия

Первоисточники: обе книги `JV-...08.10.2026.xlsm` из родительской папки репозитория. Исходные SHA-256 сверяются скриптом `tools/jv/capture-slider-bom-pr11i.ps1` с фикстурой PR_11A. Excel 16.0 пересчитывал только временные копии через `CalculateFullRebuild`. Подробные результаты: `fixtures/slider-pr11i-bom-capture.json` и `SLIDER_X5_EXCEL_PARITY.json`.

## Маршрут

`Главная!F11=6` означает Slider-X5. В обеих книгах `Главная!G11=3` по `=IF(OR(F11=4,F11=5,F11=6),3,IF(F11=11,10,F11))`, `S1!A3=1`, `S1!C8=20` (X), `S1!C9=5` (пять дорожек), `S1!C10=C8+C9=25`. `Главная!C11/D11/M11/J11` переходят в `S1!D3/D4/D5/D6`; направление 1/2 даёт одну сторону, 3 — две. `S1!D17/D18` вычисляются в DAG из исходных индексов `Настройки!I15/I17`, `S1!C17/C18` и таблиц `#1!F17:F18/G17:G18` (ДА/НЕТ). Готовые значения D17/D18 из Excel не являются входами движка.

| Выход | Исходная зависимость |
| --- | --- |
| `C8/C9/C10` | Селектор F11: X=20, дорожек=5, сумма=25. |
| `D17/D18` | `IF` + `INDEX` по `#1`; индекс 3 в настройке переключает управление на C17/C18. |
| `D31` | `ROUNDUP(D3-IF(AND(C8=20,D18="ДА"),2*Настройки!S6,0),0)`. |
| `D32` | `ROUNDUP(D3-IF(D18="ДА",2*Настройки!S6,0),0)`. |
| `C13` | Четыре ветви `D17/D18` выбирают `Настройки!S9:S12`. |
| `C14` | При `D6=2` выбирается `Настройки!S13/S14` переключателем `H25`; иначе 0. |
| `D43` | `ROUNDUP((D3+(D5-D6)*S2-2*C13-C14)/D5,0)+L23`. |
| `D44` | Для `C10=25` высота `D4-Настройки!S24`; X3 использует S23. |
| `D33/D34/D45` | `D43+S4`; при `D6=2` — `D33+S3`, иначе формульный 0; `D43+2*S3`. |
| `D37` | При `D18="ДА"` возвращает D4, иначе 0; промежуточный узел раскроя. |
| `J6/J10` | Сравнение C9 с I6=5 и C10 с I10=25 активирует соответствующие строки. |
| `K6/K10` | Верхний пятидорожечный профиль `D32/1000+D8/1000` и X-опора `D31/1000+D8/1000`; условие `J6/J10>0`. |

Исполняемый код: `packages/shared/src/jv/slider/x5-geometry.ts`, экспорт `calculateSliderX5Geometry`. Каждая вычислительная ступень имеет исходный адрес, формулу и trace; арифметика — `ExactRational`, Excel `ROUNDUP` применяется только в исходных правилах. Входные размеры — мм, профильные количества — погонные метры. В отличие от X3 изменяются C9/C10, S24 и активные K6/K10; у L5 C8=10 и активна L-опора K8. Общие с X3 формулы остальных геометрических ячеек сохранены по тем же точным выражениям из S1.

Пять конфигураций на книгу покрывают ширины 2400–4200 мм, высоты 2100–2500 мм, 2–4 створки, все три ветви открывания и варианты межстворочных переключателей. Семь возвращаемых размеров сверены в каждом случае. Это подтверждение охвата этих сценариев, а не всех допустимых размеров и опций Excel.
