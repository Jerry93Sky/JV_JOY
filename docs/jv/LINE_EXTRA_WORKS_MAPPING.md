# JV-Line: дополнительные позиции O45:O50

Источник — формулы `L1!O45:O50`, их подписи и строки `Прайс-Line`, пересчитанные Excel 16.0. Движок использует отдельные позиции и не сливает их с базовым BOM.

| L1 | SKU | Формула количества | Источник цены / правила |
|---|---|---|---|
| O45 | AA-020 | `(2*O5 + IF(D18="ДА",2*O6,0) + IF(D15="ДА",O8,0))/Настройки!L8` | `'Прайс-Line'` строка товара; P/Q через дополнительный модуль |
| O46 | AA-050 | `IF(D15="ДА",D5-1,D5+1)` | `'Прайс-Line'` строка товара |
| O47 | AA-070 | `IF(D15="ДА",2,0)` | `'Прайс-Line'` строка товара |
| O48 | AA-090 | `IF(D9=90,D8,0)` | `'Прайс-Line'` строка товара |
| O49 | AA-110 | `ROUNDUP(0.001*2*D3/Настройки!L4, IF(Настройки!L6,0,3))` | `'Прайс-Line'`; подтверждён переключатель точности L6 |
| O50 | AA-120 | `ROUNDUP(0.001*2*D3/Настройки!L5, IF(Настройки!L6,0,3))` | `'Прайс-Line'`; подтверждён переключатель точности L6 |

В формулах P/Q для AA-020/050/070/090/110/120 сохранены раздельные source cells. Для AA-020 участвует L8. Для ветки клея коэффициенты `'Клей+акт'!O5/O18` зависят от конкретной конструкции; они не являются постоянными полями прайс-снимка.

Текущие проверки на 12 сценариях: количества — 72 сравнения; P/Q — 144. Ни одного MISMATCH; часть результатов совпадает только по формату отображения Excel и отмечена `DISPLAY_MATCH`. Нулевое количество остаётся строкой с нулём, а отсутствие обязательного параметра — неподдержанным входом, не нулём.

Источник реализации: `packages/shared/src/jv/additional-line.ts`, `pricing-line.ts`; parity runner: `tools/jv/verify-line-additional-parity.mjs`.
