## Тестирование коллегами и дальнейшая работа

Для установки используйте [README](../../README.md) и [пошаговую инструкцию](TESTING_LATEST.md). **Тестовая сборка — не для самостоятельного коммерческого выпуска без контроля.** Полной Excel parity пока нет. КП выпускается только из подтверждённого расчёта. Счёт доступен в форме проекта. Автоматизированное выставление, налоги, оплата и безопасная интеграция со складом требуют отдельных решений. Этапы R6–R8 остаются в [дорожной карте](../../ROADMAP.md).

Следующие работы планируются короткими ветками от актуального `main`. Каждый PR должен покрывать одну задачу с проверками и CI. Незавершённые изменения остаются в отдельных ветках.
