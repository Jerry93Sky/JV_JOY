# Профиль Front с дверью

`JV-FRONT-FITTINGS-I42-2-PR15A-1` — серверный профиль проверенного примера, а не весь ассортимент дверей. Он доступен для COMPLETATION и RETAIL с соответствующими источниками цен и SHA-256 в серверном каталоге. Версия правил — `JV-UNIFIED-ORDER-PR13E-1`. Данные `Настройки!I42=2`, `H44=1`, справочники и цены подставляет сервер; клиент отправляет только идентификатор конфигурации и разрешённые поля. Старый профиль I42=1 не изменён.

| Узел | Проверенное значение | Источник |
| --- | --- | --- |
| Front, слот 7 | ширина 3300 мм, высота 2350 мм, 3 секции, J17=1 | `Главная!C17:D17`, `J17`, `L17` |
| Отделка, стекло | COMPLETATION: H17=1; RETAIL: H17=2; I17=9 | `Главная!H17:I17` |
| Дверные переключатели | C18=1, C19=2, C20=2, C21=2, C22=8, C23=10, C24=2; D18=1000, D19=2150 мм | `F7!C18:C24`, `D18:D19`; основа: сценарий fittings F1 |
| Доводчик | C21=2 → `Прайс-Аксессуары!D59` | `F7!R27=IFERROR(INDEX('Прайс-Аксессуары'!D59:D61,$C$21-1),0)` |
| Транспорт | F28=1 или 2; B26=1 | `Главная!F28`, `B26`, `F7!S36`; B26=1 задан в сценарии, в исходной книге B26 пуста |
| Состав и количество | Line, Zigzag, Slider L3/L5/X3/X5, Front в слотах 1–7; по 1 шт. | `fixtures/front-door-all-seven-inputs.json` |

Сервер проверяет все параметры семи позиций по соответствующему контрольному шаблону, разрешая только переключение F28 между 1 и 2. Запрос с другими размерами, фурнитурой, количеством, составом, слотом или версией отклоняется; это не означает, что такие конструкции физически невозможны. Клиент не может менять settings, прайс или B26. Legacy и JV-UI-INPUTS-1 не принимают новый профиль; существующие запросы без идентификатора работают по прежним правилам. В ответе присутствуют `versions.configurationProfiles` и trace `JV.FRONT.PROFILE.I42`.

Frontend предлагает загрузить фиксированный пример только в пустой заказ и показывает ограничения. В этом примере пользователь может менять транспорт и ценовой профиль; остальные поля зафиксированы. Все неподтверждённые двери, комбинации фурнитуры, одиночный Front и F1 в составе заказа остаются ограничены. Для одиночного теста временная копия Excel с отключёнными остальными строками вернула `Главная!AA18=#ЗНАЧ!`; выводить её как подтверждённый числовой эталон нельзя. Наблюдение сохранено в `fixtures/front-door-isolated-excel.json`.
