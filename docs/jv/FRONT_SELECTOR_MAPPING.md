# JV-Front: маршрут выбора

Источник: оригинальные `JV-комплектация 08.10.2026.xlsm` и `JV-розница 08.10.2026.xlsm`. Проверка выполнялась Excel 16.0 `CalculateFullRebuild` на временных копиях. Хэши исходников и входы сценариев записаны в `fixtures/front-pr12a-excel.json`.

| Узел | Формула / источник | Факт |
| --- | --- | --- |
| `Главная!F11` | пользовательский системный селектор | `7` включает Front |
| `Главная!G11` | `=IF(OR(F11=4,F11=5,F11=6),3,IF(F11=11,10,F11))` | `7` |
| `F1!A2` | `=IFERROR(Главная!$G$11,0)` | `7` |
| `F1!A3` | `=IF(A2=7,1,0)` | `1` |
| `Главная!M11` | `=CEILING($L11,1)` | исходный ввод числа секций `L11` округляется вверх |
| `F1!C3:C5` | `Главная!C11`, `D11`, `M11` | ширина, высота, число секций после `CEILING` |
| `F1!C6:C7` | `Главная!H11`, `I11` | отделка, тип стекла |
| `Главная!K11` | `=IF(J11<=2,1,J11-1)` | исходный ввод `J11` переходит в `F1!C8` |
| `F1!C8` | `=Главная!$K$11` | `1` — одна створка, `2` — две, `3` — без створки |
| `F1!S38` | `=IF($I$23="ОШИБКА!",$I$23,SUM($S$36:$S$37))` | финальная стоимость конструкции |
| `Главная!X11` | `='F1'!$S$38/Настройки!$D$14` | Front в системной колонке X |
| `Главная!Y11` | `=INDEX(R11:X11,G11)*(100+Настройки!$D21)/100` | цена с наценкой |
| `Главная!AA11` | `=Y11*Z11*(100+Настройки!$D$19)/100` | стоимость позиции с количеством |

Формулы `Главная!G12:G17` и `X12:X17` повторяют маршрут для `F2:F7`: доступно семь слотов заказа. `F1:F7` являются расчётными листами одной семьи, а не семью подтверждёнными технологическими вариантами. Новый калькулятор получает параметры одной конструкции и не подключён к заказу.

Подтверждённые конструктивные переключатели: `F1!D11` выбирает зажимной или П-образный профиль через `Настройки!I34=H38`, `#2!C6:C7` и `F1!C11`; `F1!D12:D14` используют `Настройки!I36=H40`, `I38=H42`, `I40=H44`; `D15` использует `I44`. Их каталоги — `#2!E/F/L6:7`. `F1!C18` выбирает автоматическую или заданную ширину створки (`D18`); `C19` управляет фрамугой; `C20:C24` управляют фурнитурой. `F1!I17:I22` формируют ошибки, `I23` объединяет их. При исходном `Настройки!I42=1` и `C8<3` Excel возвращает ошибку; сценарии дверей включают `I42=2` только во временной копии.

Экспортируемый `calculateFront` принимает исходные `Главная!Jslot` и `Lslot`, вычисляет `Kslot` и `Mslot` внутри DAG, затем `F1!C8` и `C5`. Вычисленные ячейки Excel не являются входом функции.
