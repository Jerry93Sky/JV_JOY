# Тест-кейсы и получение эталонов

## Матрица сценариев
Для обеих книг: профиль отдельно; LINE, ZIGZAG, SLIDER_L3/L5/X3/X5, FRONT; базовый допустимый ввод, нижняя/верхняя границы, каждый dropdown/переключатель, некорректная комбинация, 1/7/8+ позиций. Проверять геометрию, BOM по SKU, раскрой/припуски, ПД, стекло/обработку, покраску, сборку, монтаж, аксессуары, доставку, скидку, CC и Клей+акт.

## Арифметические границы
- ROUND: +1.5, -1.5, +2.5, -2.5 и десятичные разряды; Excel half-away-from-zero сверить свежим Excel.
- ROUNDUP/ROUNDDOWN/CEILING для обоих знаков, нулей и кратных; не приравнивать к JS Math.
- INDEX/MATCH: первая строка (index 1), последняя, 0, отрицательный и выход за диапазон; mismatch выдаёт ошибку Excel, не 0.
- IFERROR/пустое/текст/деление на ноль; проверять только выбранную ветвь. SUM/AND/OR/ISEVEN/CONCATENATE/TODAY с локалью и типами.
