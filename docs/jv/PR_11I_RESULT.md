# PR_11I — Slider-X5 geometry and BOM

База: PR_11H `c4878e79638df3da2f8f2927c1b57f254d77d1bd`; отдельная ветка `feature/jv-slider-x5`. Изменены только новые JV-модули, их экспорт, аналитические инструменты, фикстура и документация. Legacy `/calculate`, Prisma, React, предыдущие Slider-калькуляторы и их контракты не менялись.

## Работающий результат

- `packages/shared/src/jv/slider/x5-geometry.ts`: экспорт `calculateSliderX5Geometry`; исходные размеры, створки, открывание и raw селекторы → D17/D18, C8/C9/C10, C13/C14, D31/D32/D33/D34/D37/D43/D44/D45, J6/J10, K6/K10. Правила выполняются через DAG с BigInt `ExactRational`, typed errors, версией, Excel-адресом, исходной формулой и trace.
- `packages/shared/src/jv/slider/x5-bom.ts`: экспорт `calculateSliderX5FullBom`; D20/D22/D24/D26 разрешаются из `Настройки` и `#1`, затем рассчитываются все 29 применимых количества из S1!K5:K46. 13 строк помечены `NOT_APPLICABLE`, а применимые формульные нули сохраняются как рассчитанные значения. Для каждой позиции есть артикул, если подтверждён, единица, каталог, формула, версия и trace. K40/K41 остаются расходом конструкции без начисления закупочной упаковки.
- `packages/shared/src/jv/index.ts`: оба API доступны из существующего JV Engine. Исполняемая коммерческая цена X5 здесь не добавлена.
- `packages/shared/src/jv/slider/x5.test.ts`: два новых автоматических теста, первый проходит десять Excel-сценариев и проверяет геометрию, все 42 BOM-адреса и селекторы; второй проверяет ошибки выбора, размеров, створок и отсутствующей настройки.

## Источники и Excel parity

`tools/jv/capture-slider-bom-pr11i.ps1` сверяет SHA-256 исходных книг с уже зафиксированными идентификаторами PR_11A, создаёт временную XLSM-копию для каждого профиля и вызывает Excel 16.0 `CalculateFullRebuild`. Источники не изменялись. `docs/jv/fixtures/slider-pr11i-bom-capture.json` содержит пять конфигураций на комплектацию и пять на розницу: ширина 2400–4200 мм, высота 2100–2500 мм, 2–4 створки, открывание 1/2/3, H21/H19/H25/H27, замки, ручки, L6. Для каждой записаны raw управляющие ячейки, `S1!A3/C8/C9/C10`, J-селекторы всех 42 строк, маршрут M53→T11/Y11, формулы и `NumberFormat` 42 количеств.

Маршрут пересчёта: `Главная!F11=6 → G11=3 → S1!A3=1`, `C8=20`, `C9=5`, `C10=25`; `S1!M53` передаётся через `Главная!T11` и `Y11`. Сам коммерческий M53 не сравнивается с новой реализацией, так как она относится к PR_11J.

`tools/jv/compare-slider-x5-pr11i.mjs` независимо вызывает новый движок с исходными размерами, сырыми селекторами и значениями справочника, сверяет формулы, все семь возвращаемых геометрических размеров, шесть разрешённых селекторов и 42 строки BOM. В `SLIDER_X5_EXCEL_PARITY.json` для каждой ячейки сохранены формула, Excel Value2, формат, точный рациональный результат, отображаемое значение, trace и класс сравнения.

| Класс | Число |
| --- | ---: |
| EXACT | 410 |
| NUMERICALLY_EQUIVALENT | 0 |
| DISPLAY_MATCH | 10 |
| MISMATCH | 0 |
| UNVERIFIED | 130 |

Десять `DISPLAY_MATCH` приходятся на двоичный остаток Excel Value2 для K6/K10/K11/K13; форматированное значение совпало, но внутреннее рациональное равенство не заявляется. 130 `UNVERIFIED` — это 13 формульно неприменимых строк × 10 сценариев, а не отсутствующие применимые количества. Применимы 29 строк, неприменимы 13; у первых 12 неприменимых J-селектор равен нулю, K45 выводится из K29. Перечень и доказательства — в `SLIDER_X5_BOM_RULES.md` и `SLIDER_X5_BOM_COVERAGE.json`. При отдельной сверке текстовых селекторов обнаружено, что `#1!F26` даёт `НЕТ` в верхнем регистре; X5 таблица исправлена до нулевого числа расхождений.
