# Zigzag: правила цен и стоимости

Состояние: реализованы как независимая ветка JV Engine. Legacy `/calculate`, API и база данных не подключались.

## Версионированные источники

`fixtures/zigzag-price-snapshots.json` содержит два независимых профиля, построенных из исходных книг после Excel 16 `CalculateFullRebuild`:

- комплектация — `62dd6d49f059bef840b67713a0ea6a9f1dec0ec90cf364563cf423dac376d2d8`;
- розница — `025d7e2911176ca0b0cdb445574565cd8e3f44d814905cd4c474999630c7ab41`.

Снимки содержат исходные литералы, адреса и версии листов `'Прайс-Line'`, `'Прайс-сб+монт'` и `'Прайс-Стекло'`. Вычисленные ячейки O/P не используются как исходные цены. Построитель `buildZigzagPriceSnapshot` проверяет хеш профиля, адреса цен, идентификаторы SKU, единицы измерения, формулы, коэффициенты и буквальные значения.

**Подтверждённое исправление каталога:** прежний BOM связывал N9 с LN-070-A. Excel `Z1!O9` ссылается на E11, где строка каталога содержит LN-060 «Роликовая каретка низкая». Обновлён идентификатор BOM на LN-060. Формула количества N9 не менялась.

N31 имеет рациональное количество `6017/475` для проверенного сценария. Оно хранится в `SpecificationLine.exactQuantity` и используется для цены; конечная десятичная Quantity не фабрикуется.

`Z1!P38=SUM(P5:P35)` публикуется только когда доступны все 31 строки, включая общие коэффициенты P34/P35. Иначе результат содержит `supportedSubtotal`, статус `PARTIAL`, явные недоступные позиции и не содержит P38.

## Дополнительные расходы

- `P39=IF(C8<>1,U18,0)`. Ветка C8=1 даёт ноль без обращения к U18. Иначе U18 рассчитывается по U10:U14, U15=`MAX(U10:U14)`, U17=`'Прайс-сб+монт'!C24*W5`. Для U5:U13 используются исходные G5:G10/G39:G40, N5:N10, явные N40/N41 и множитель L11 при C8=4. Пустые N40/N41 не подразумеваются автоматически: входы передаются явно.
- `P40=IF(Настройки!D32,H33,0)`. Включённая ветка восстанавливает цену стекла через selector `Главная!I11`, исходную таблицу `'Прайс-Стекло'!D5:D16`, геометрию D28:D31, количества C29:C31, H26:H29 и `H33=H29+'Прайс-сб+монт'!C23*W5`.
- `P41` рассчитывается отдельно по двум переключателям: ширина × C6 / 1000 и N10 × C19.
- `P43` рассчитывается при включённом D34 по ширине, высоте, числу створок и C8/C9/C13.
- `P42=P38+P39+P40+P41+IF(F28=2,C25*W5,0)` и `P44=P42+P43`. Итоги доступны только если замкнуты их применимые зависимости.

Числовые значения и детальные статусы Excel parity находятся в `ZIGZAG_PRICE_PARITY.json`; входные пересчёты, формулы, Value2, IEEE-754 bits, отображение и форматы — в `fixtures/zigzag-pricing-excel.json`.
