# PR_06 — следующий шаг

## Цель

Продолжить JV-Line на независимой расчётной ветке от проверенного BOM и профилей цены, не меняя legacy `/calculate`, Prisma, базу данных или UI.

## Приоритетные задачи

1. Перенести и замкнуть створочные геометрические строки `L1!C36:D41` → `F33:F39` → `O6:O7` для LN-020/LN-030. Использовать исходные формулы и справочники Excel, а не числовые кэши.
2. Завершить независимую парковочную ветку: D23/D24, O12:O16, таблицы ПД и связанные проверки допустимых позиций/размеров. Импортированные матрицы ПД сверять с исходными диапазонами обеих книг.
3. Подключить LN-100/110/120/130/190/200 к подтверждённым зависимостям предыдущих строк после завершения парковочной ветки.
4. Реализовать AA-010 только после независимого подтверждения O7 и точного поведения `ROUNDUP`/параметров `Настройки!L7/P21`.
5. Для каждой новой формулы добавить трассу входов, каталог/версию прайса, тесты границ и Excel COM golden cases минимум для обеих книг.
6. Исследовать формулы массы `S` и покраски `V` отдельно; не включать их в стоимость без подтверждения единиц, коэффициентов и порядка вычислений.
7. Не считать поддержанную промежуточную сумму полной себестоимостью. До запуска следующего PR подготовить ясный список применимых позиций для каждой конфигурации и отсутствие скрытых defaults.
8. После замыкания основных 40 строк расширить BOM на дополнительные позиции `L1!O45:O50` (AA-020…AA-120); для AA-110/AA-120 подтвердить Excel `ROUNDUP` precision switch `Настройки!L6` и external coefficients `'Клей+акт'!O5/O18`.
9. Отдельным этапом исследовать и реализовать граф `Q52:Q58`: групповой BOM total, painting, conditional work, assembly/milling, installation, extra options and error guard. Прежде проверить цены листа `Прайс-сб+монт`, inputs D54/X5, переключатели и другие выходные totals. Не подменять Q58 простой суммой Q52.

## Открытые ограничения PR_05

- После передачи всех Excel-resolved параметров доступна 26-строчная спецификация; 14 строк остаются неподдержанными. При отсутствии условных входов результат маркирует условные строки неподдержанными.
- Сумма `Q` реализована точно как рациональная, но общий subtotal не сравнивался с отдельной Excel aggregate ячейкой.
- Excel `Q52` суммирует Q5:Q50, включая шесть дополнительных строк после базового каталога; Q58 добавляет следующие работы и монтаж. Эти строки и aggregate formulas обнаружены и задокументированы, но не включены в engine.
- Сохранённый заголовок прайса `CC` не расшифрован.
- Паритет подтверждён на пяти конфигурациях в каждой книге, не на полном пространстве комбинаций и размеров.
- Не переносить коммерческую наценку/скидку/монтаж без отдельного графа формул и прайсовых источников.
