# PR_15A — незавершённая работа

База: опубликованный `feature/jv-full-ui`, коммит `b2017c9444cf722133607169fa571450c410b7d2`. PR_15A не завершён: страница пока не выполняет расчёт и не является полноценным редактором заказа.

## Реализовано

- Защищённый приложением маршрут `/jv/orders/new`; пользователям вне ролей `OWNER` и `ADMIN` отображается отказ. Пункт «JV-заказы» виден только этим ролям в desktop и прокручиваемой мобильной навигации.
- Черновик в памяти страницы: до семи позиций, выбор семейства и уникального слота, количество строкой, дублирование, удаление и перемещение в списке без изменения слотов. При заполнении семи слотов показывается ограничение.
- Кнопка расчёта отключена: неполные входные данные не отправляются и цена не выдумывается. Сохранение заказа не реализовано.

## Не выполнено

Формы семи семейств, ввод параметров, использование `calculateJvPreview`, обработка ответов COMPLETE/PARTIAL и запросов, инвалидация результатов, race-condition защита, пользовательские сценарии и all-seven UI-интеграция остаются не реализованы. Черновик позиции содержит только семейство, слот и количество; дублирование пока копирует только эти данные. Страница явно сообщает об этом.

Backend `validateShape` в `apps/backend/src/domain/jv/jvCalculationService.ts` требует для каждой позиции полную вложенную структуру и проверяет `settings` и `bomSettings` на полное совпадение с серверным snapshot. Отдельного маршрута получения непрайсовой схемы и настроек в текущем API нет. Для завершения нужно безопасно обеспечить эти входы из подтверждённого источника и реализовать все формы; текущий экран их не имитирует.
