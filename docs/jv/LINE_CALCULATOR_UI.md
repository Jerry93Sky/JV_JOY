# JV-Line Lab — изолированный тестовый интерфейс

## Доступ

Авторизованный маршрут приложения: `/jv-line-lab`, пункт боковой панели «JV-Line Lab». Страница вызывает только синхронный `calculateLineConstruction` из `@bms/shared` и локальный read-only JSON-снимок справочников. Она не вызывает API, не читает/пишет БД и не сохраняет конструкцию.

## Что можно проверить

- Профиль «Комплектация» и «Розница».
- Размеры, число полотен/сторон, направление, угол 90/135, профильные состояния.
- Опции фурнитуры и паркуемой двери, специальное полотно.
- Переключатели монтажа/сборки/фрезеровки.
- Геометрию и резы, все 40 строк BOM, дополнительные количества, доступные строки стоимости, Q55/Q57, диагностики и трассу.

Исходный пример — `line_single_no_park`, пересчитанный Excel-сценарий. Справочные цены и настройки являются снимками книг, а не динамическим импортом. Они помечены происхождением в `reference-data.json`.

## Ограничения результата

Страница всегда показывает статус `PARTIAL` и не предлагает итоговую цену. Q52 отображается как частичная сумма. Стоимости клеевых AA-110/AA-120 не строятся из параметров конструкции, пока не реализованы O5/O18 из `Клей+акт`; количество этих позиций остается видимым. Q53/Q54/Q56/Q58 не представлены как рассчитанные правила.

Маршрут проходит сборку frontend (TypeScript + Vite). Vite dev server отдал `/jv-line-lab` с HTTP 200 и SPA entrypoint. Визуальный интерактивный сценарий страницы не проверялся; сам клиентский экран защищён существующей авторизацией приложения.
