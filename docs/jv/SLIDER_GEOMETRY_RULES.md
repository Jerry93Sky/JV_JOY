# Геометрия Slider-L3

Источник: обе книги Excel, лист `S1`; вариант подтверждён `Главная!F11=3`, `G11=3`, `S1!C8=10`, `C9=3`, `C10=13`. Реализация — `packages/shared/src/jv/slider/geometry.ts#calculateSliderL3Geometry`.

## Входы

- `Главная!Cslot/Dslot/Mslot/Jslot`: ширина, высота, число створок, selector открывания.
- `Настройки!S2/S3/S4/S6/S9:S14/S21/L23/D8/H25`.
- Выборы `S1!D17/D18`, которые в исходной книге уже разрешены через `Настройки!I15/I17` и `#1`.

Неизвестные/отсутствующие settings являются ошибкой, не заменяются нулём. Размеры и количества — точные десятичные входы; правила Excel `ROUNDUP(...,0)` используют рациональную арифметику.

## Вычисляемые правила

| Ячейка | Формула Excel | Результат |
|---|---|---|
| C8/C9/C10 | selector expressions; для F11=3 дают 10, 3, 13 | код L-системы и 3 дорожки |
| D31 | `=ROUNDUP(D3-IF(AND(C8=20,D18="ДА"),2*S6,0),0)` | ширина верхней системы |
| D32 | `=ROUNDUP(D3-IF(D18="ДА",2*S6,0),0)` | ширина верхней направляющей |
| C13 | четыре ветви D17/D18 выбирают S9/S10/S11/S12 | профильный вычет для створки |
| C14 | если D6=2, выбрать S14 при H25, иначе S13; иначе 0 | вычет стыка |
| D43 | `=ROUNDUP((D3+(D5-D6)*S2-2*C13-C14)/D5,0)+L23` | ширина створки |
| D44 | `=D4-IF(C10=13,S21,0)-IF(C10=15,S22,0)-IF(C10=23,S23,0)-IF(C10=25,S24,0)` | высота створки; L3 использует S21 |
| D33/D34/D45 | `D43+S4`; `IF(D6=2,D33+S3,0)`; `D43+2*S3` | зависимые длины элементов |
| D37 | `=IF(D18="ДА",D4,0)` | высотная добавка для BOM ряда 7 |
| K5/K7 | точные исходные строки приведены в `SLIDER_BOM_COVERAGE.json` | количество верхнего 3-track и L-опорного 3-track профилей |

Каждое правило реализовано узлом существующего DAG с source cell и формулой в trace. Все вычисления exact rational; не добавлено округление сверх исходного `ROUNDUP`.

## Проверенное parity покрытие

Две конфигурации: 3000×2200 мм, 2 створки, открывание 1; и 3600×2400 мм, 4 створки, открывание 3. Повторено в комплектации и рознице. `S1!D31:D34`, `D43:D45`, `K5`, `K7`: 36 сравнений, все EXACT. Дополнительные F11=4..6 подтверждают селекторные коды C8/C9, но не означают реализацию геометрии L5/X3/X5.

Числовой диапазон минимальных/максимальных габаритов и все варианты внутренних выборов требуют дальнейших Excel сценариев. Этот модуль не объявляет полный размерный диапазон Slider поддержанным.
