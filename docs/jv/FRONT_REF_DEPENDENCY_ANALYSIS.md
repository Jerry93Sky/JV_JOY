# PR_12B2: зависимость ПРМ!R25 с #REF!

Проверены формулы обеих оригинальных XLSM и значения после Excel 16 CalculateFullRebuild на восьми временных копиях. Оригиналы не сохранялись после открытия.

ПРМ!R25 = IFERROR(IF(L25=7,'F1'!#REF!,0)×Главная!Z11,0). При активном Front L25=7 повреждённая ссылка скрывается IFERROR, и Excel возвращает 0. В восьми контрольных сценариях ПРМ!R25=0 для обоих профилей.

Непосредственная исходная цепочка доли иная:

1. ПРМ!U25/V25/W25 = Главная!C11/D11/Z11; AA25 = IFERROR(U25×V25×W25/1000000,0).
2. AA25:AA31 вычисляют площади строк заказа; AA32 = SUM(AA25:AA31).
3. AB25 = IFERROR(AA25/(AA32×W25),0); F1!Y5 = ПРМ!AB25.
4. Y5 входит в F1!D35, W20, W23 и условную добавку S36.

R25 не входит в эту цепочку. Например, в COMPLETATION-base после полного пересчёта R25=0, AB25=Y5=0.0990990990990991 (точная доля 11/111). В COMPLETATION-wide доля 18/161 при R25=0. Поведение повторяется в розничной книге. Перенос #REF! как входа Y5 был бы ошибкой.

R25 входит в другую цепочку: ПРМ!R32 = IFERROR(SUM(R25:R31),0); R33 = M32+N32+R32; R34 = ROUNDUP(R33/70,0). Прямой поиск формул всех листов не обнаружил потребителя ПРМ!R34 в F1!S33:S38 или Главная!S11. Поэтому по проверенному графу R25 не влияет на цену Front, стекло и расходники. Повреждённую ссылку нельзя самовольно исправлять; если появится непрямая ссылка, именованный диапазон или макрос, риск потребуется пересмотреть. Остальные системы, участвующие в R32, данным выводом не покрываются.

Фактические Value2, NumberFormat и формулы: fixtures/front-commercial-components.xlsx.json. R25 сохранён в захвате для диагностики и не выдаётся как вычисленный выход нового движка.
